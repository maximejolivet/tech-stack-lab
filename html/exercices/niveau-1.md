# Exercices HTML — Niveau 1 (Bases)

## Exercice 1.1 — Squelette valide

Écris un document HTML5 complet et valide (`<!DOCTYPE>`, `lang`, `charset`, `viewport`, `title`) pour une page dont le titre est "Ma première page".

## Exercice 1.2 — Hiérarchie de titres

Crée une page avec un `<h1>` "Mon blog", puis deux articles, chacun avec son propre `<h2>` comme titre d'article. Utilise la balise sémantique adaptée pour chaque article (pas de `<div>`).

## Exercice 1.3 — Liste et liens

Crée une liste non ordonnée de 3 liens de navigation (`Accueil`, `Blog`, `Contact`) vers `/`, `/blog`, `/contact`, placée dans une balise `<nav>` correcte.

## Exercice 1.4 — Image accessible

Insère une image `chat.jpg` qui illustre un article sur les chats de race Siamois. Écris un `alt` pertinent. Ajoute les attributs qui évitent un décalage de mise en page (*layout shift*) pendant le chargement.

## Exercice 1.5 — Repérer l'erreur

Que ne va pas dans ce code ? Corrige-le.

```html
<div class="titre">Bienvenue</div>
<div onclick="goToContact()">Contactez-nous</div>
<img src="logo.png">
```
