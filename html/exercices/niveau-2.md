# Exercices HTML — Niveau 2 (Intermédiaire)

## Exercice 2.1 — Formulaire de contact complet

Crée un formulaire de contact avec :
- un champ nom (texte, requis, 2 caractères min),
- un champ email (type adapté, requis),
- un champ téléphone (type adapté, optionnel),
- un menu déroulant "Sujet" (`Support`, `Commercial`, `Autre`),
- un champ message (zone de texte, requis, 500 caractères max),
- un bouton d'envoi.

Chaque champ doit avoir un `<label>` correctement lié. Ajoute `autocomplete` sur les champs pertinents.

## Exercice 2.2 — Tableau de données

Construis un tableau présentant le budget mensuel d'un foyer (Catégorie / Prévu / Réel) sur 4 lignes, avec un `<caption>`, un `<thead>` et les attributs `scope` corrects sur les en-têtes.

## Exercice 2.3 — FAQ accessible sans JS

Construis une FAQ de 3 questions/réponses en utilisant uniquement du HTML natif (pas de JS), où chaque réponse est repliée par défaut et dépliable au clic/clavier.

## Exercice 2.4 — Page correctement structurée pour le SEO et le partage

Écris le `<head>` complet d'une page d'article de blog : title unique, meta description, canonical, balises Open Graph (titre, description, image), favicon.

## Exercice 2.5 — Menu accessible avec ARIA

Construis un bouton "Menu" qui contrôle une liste `<ul>` cachée par défaut (`hidden`). Ajoute les attributs ARIA nécessaires pour indiquer l'état ouvert/fermé du menu à un lecteur d'écran (le comportement JS n'est pas demandé, seulement le HTML/ARIA correct).
